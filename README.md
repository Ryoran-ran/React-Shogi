# 将棋からはじめるボードゲームメーカー

同じ端末で2人が交互に指すほか、簡易AIとの対局やAI同士の動作確認ができる将棋です。盤面の大きさと初期配置も編集できます。

## 起動

Bun が必要です。初回は `bun install` で開発用の型定義を含む依存パッケージをインストールしてください。

```powershell
npm run dev
```

ブラウザで **http://localhost:5173** を開いてください。以前のサーバーが動いている場合は `Ctrl+C` で止めてから起動し直します。編集後はブラウザを再読み込みしてください。

## タイトルから遊び方を選ぶ

起動時はタイトル画面から始まります。

- **普通の将棋**：9×9の平手・パスなしで新しい対局を始めます。2人対局とAI対局を選べます。
- **エディットで遊ぶ**：「新規」「編集」「遊ぶ」のメニューを開きます。「新規」は空の盤面から作成、「編集」は保存した配置を修正、「遊ぶ」は完成済みの配置を選んで直接対局します。配置ファイルから編集・対局することもできます。

保存した配置はプレビュー付きで表示します。作成途中の配置は編集でき、王・玉などの配置を整えると対局できるようになります。

保存した配置の「コピーして作成」では、元の配置を残して新しい配置を編集できます。名前は「元の名前のコピー」のように重複しない候補を付けます。編集中の保存済み配置一覧にある「コピー」からも利用できます。コピーを開いただけでは保存せず、保存操作を行うと新しい配置として追加します。

前回の対局がある場合は「対局の続きから」で再開できます。終局済みの場合は「前回の対局を見る」で結果や棋譜を確認できます。対局画面や結果画面の「タイトルへ」で戻れます。タイトルやエディットのメニューではAIは進行せず、対局画面へ戻るとモードに応じて再開します。

## 指し方

1. 先手の駒をクリックします。移動できるマスに印が付きます。
2. 移動先をクリックすると、後手の手番になります。
3. 成れる場合は「成る」「成らない」を選びます。行き所がなくなる場合は自動で成ります。
4. 持ち駒をクリックし、印が付いたマスを選ぶと打てます。

選んだ駒をもう一度クリックするか、Esc キーで選択を解除できます。「一手戻す」「盤面を反転」「投了する」「新しく始める」も使えます。

決着すると、勝者・決着理由・手数を結果画面で表示します。AI対局では自分の勝ち負けに合わせて演出が変わります。「終局した盤面を見る」または Esc キーで閉じ、棋譜や盤面を確認できます。「結果を見る」で再表示でき、結果画面から棋譜の保存や次の対局にも進めます。

対局と盤面の向きは、このブラウザに自動保存します。「棋譜を保存」で独自の JSON 形式に書き出し、「棋譜を開く」で続きを再開できます。KIF・CSA 形式には対応していません。以前のメーカーの保存内容は別のキーで残っています。

## 盤面と駒の配置を編集する

タイトルの「エディットで遊ぶ」から「新規」または「編集」でエディット画面を開きます。エディット対局中は画面上部の「配置を編集」からも開けます。編集中はAIを停止し、元の対局を保持します。「編集をやめる」または Esc で、開く前のメニュー・対局へ戻れます。

1. 「横のマス数」「縦のマス数」をそれぞれ3〜15で設定します。長方形にも対応しています。
2. 先手・後手と駒の種類を選び、盤面をクリックして配置・上書きします。「成った駒を置く」で成駒も配置できます。
3. 「消しゴム」で駒を取り除けます。同じ側の王・玉を置き直すと移動します。
4. 最初の手番を選び、「この配置で対局」で新しい対局を始めます。王・玉は各側1枚必要です。手番ではない側が王手を受けている配置や、開始時点で詰んでいる配置は修正してください。

盤面を縮小すると盤外の駒は取り除かれます。「編集を一つ戻す」でサイズや配置を戻せます。「盤面を空にする」「平手に戻す（9×9）」「現在の対局の盤面を使う」も利用できます。現在の盤面を使う場合は持ち駒も引き継ぎます。

編集した盤面でも駒取り・駒打ち・王手・成り・パス・AI対局を使えます。成れる範囲は相手側の端から、縦幅の3分の1（切り捨て、最大3段）です。「新しく始める」「もう一局」では編集した初期配置へ戻ります。通常の9×9へ戻す場合はエディターの「平手に戻す」を使って適用してください。

棋譜には盤面サイズと初期配置も保存します（version 3）。以前のversion 1・2も、9×9の平手として引き続き読み込めます。

### 配置だけを保存・読み込みする

エディターの「配置の保存と読み込み」では、対局を始めずに編集中の配置を保存できます。王・玉をまだ置いていない作成途中の配置も保存できます。

- **ブラウザに保存**：配置名を付けてローカルストレージに保存します。「保存済みの配置」から「開く」で復元できます。複数の配置を最大100件保存できます。
- **上書き保存**：読み込み・保存済みの配置を更新します。元の配置を残したい場合は「別名で保存」を使ってください。
- **別名で保存**：新しい配置名を入力し、ブラウザ保存かファイル出力を選べます。新規作成中でも利用できます。ブラウザ保存では同じ名前の配置への上書きは行わず、新しい配置として追加します。ファイル出力を選んだ場合も、読み込み元のブラウザ保存は変更しません。
- **ファイルに出力**：配置を専用のJSONファイルに書き出します。別のブラウザや端末へ移す場合にも使えます。
- **ファイルを開く**：出力した配置ファイルをエディターへ読み込みます。現在の対局は「この配置で対局」を押すまで保持します。

保存内容は盤面サイズ・駒の配置と成り・持ち駒・最初の手番・パス上限です。パス上限はエディターでも設定でき、空欄は無制限、0はパスを使用しない設定です。配置名が空欄の場合は「5×7の配置」のように名前を付けます。

「別名で保存」の名前欄では Enter でブラウザに保存できます。キャンセルまたは Esc で名前入力だけを閉じ、編集を続けられます。

配置ファイルには棋譜を含めません。対局の続きを保存する場合は、対局画面の「棋譜を保存」を使ってください。ブラウザ内の配置保存はそのブラウザに保存され、自動同期は行いません。ブラウザのサイトデータを削除すると保存済み配置も消えるため、残したい配置はファイルにも出力できます。

## 追加ルール：パス

パスはエディット対局用の追加ルールです。「普通の将棋」ではパスを使用しません。

「パスする」で盤面と持ち駒を変えずに手番を相手に渡せます。王手中はパスできません。パスも1手として数え、棋譜に「▲パス」「△パス」を記録します。

初期値は無制限です。対局開始前に「パス上限（各自）」へ整数を入力すると、先手・後手それぞれの上限を設定できます。空欄は無制限、0はパスを使用しない設定です。残り回数は画面に表示し、「一手戻す」で使用回数も戻ります。「新しく始める」では上限設定を引き継ぎ、使用回数をリセットします。

AIもパスと残り回数を考慮します。連続パスだけで直ちに終局することはありませんが、無制限では同じ局面が4回現れると千日手になります。回数制限がある場合は残り回数も局面の違いとして扱います。

棋譜の保存・読み込みには、パス履歴と上限設定も含めます。以前の保存形式（version 1）の棋譜はパスなしで読み込むので、パスを使う場合は新しい対局の開始前に設定してください。

## AIで対局・動作確認する

画面上部の対局モードで選びます。

- **自分：先手 / AI：後手**：自分が指すと、AI が後手として応手を指します。
- **自分：後手 / AI：先手**：AI が先手から指します。
- **AI同士（動作確認）**：選択後に「自動開始」を押すと、両側をAIが操作します。
- **AIで1手**：現在の手番を1手だけAIに任せます。2人対局モードでも使えます。

人とAIの対戦はモードを選ぶだけで自動応手します。棋譜の読み込みや、編集画面から対局へ戻った場合も、AIの手番ならそのまま指します。再読み込み後はタイトルの「対局の続きから」で対局を開くと自動応手します。自分の手を「AIで1手」に任せた場合も、相手AIは続けて自動応手します。

「停止」を押すと停止を予約し、思考中の1手を指し終えたところで自動進行を止めます。受付後は「停止予約済み」と表示し、次の手には進みません。思考前の待機中ならその場で停止します。明示的に停止した状態は再読み込み後も保ち、「AIを再開」で自動応手へ戻れます。新しい対局や棋譜を開いた場合は、その対局モードに従って開始します。

人対AIの自動応手中は「待った」で直前の自分の手まで戻せます。AIの応手も戻して自分の手番にするため、戻した直後にAIが指し直すことはありません。AIの思考中に戻した場合は、その結果を破棄します。停止中や2人対局では、従来どおり「一手戻す」で1手だけ戻します。

AI同士は「自動開始」で進め、再読み込み後は停止状態で開きます。途中経過を確認できるよう最大200手ごとに自動停止します。人対AIでは、この200手の自動停止はありません。

「速い」「じっくり」で読む深さと計算量を切り替えられます。AIは駒の価値・利き・成り・王手などを使う簡易探索で、競技用の将棋ソフトほどの強さはありません。ブラウザ内の Worker で動き、APIキーや外部サービスは不要です。

## 対応ルール

- 全8種類の駒と成駒の動き、駒を飛び越えない移動、手番の切り替え。
- 捕獲、成駒を元に戻して持ち駒にする処理、駒打ち、任意・強制の成り。
- 二歩、行き所のない駒打ち、王手放置・自玉を王手にさらす手、打ち歩詰めの禁止。
- 王手表示、詰みの判定、投了、千日手、連続王手の千日手。
- 合意による引き分け。

ルール確認の基準：[日本将棋連盟の対局規則](https://www.shogi.or.jp/match/taikyoku_rules/)。千日手は「指し直し」として対局を終了し、「新しく始める」で再開します。入玉宣言法、持将棋の点数判定、500手による持将棋、持ち時間・秒読み、オンライン対戦は未実装です。

## 開発

```powershell
bun test
bun run typecheck
npm run build
```

`dist/` に静的配信用のファイルを生成します。型検査はアプリとテストを対象とし、Bun用の公式型定義も使います。

- `src/shogi.ts`：将棋の状態、合法手、勝敗、棋譜の保存・復元。
- `src/editor.ts`：サイズ変更、駒の配置・消去、編集の取り消し。
- `src/setups.ts`：配置ファイルの検証、名前付き配置のローカルストレージ保存・復元。
- `src/ai.ts`、`src/aiworker.ts`：計算量を制限したAI探索と画面を止めない実行処理。
- `web/app.ts`：盤面、持ち駒、成り選択、棋譜などの操作画面。
- `test/shogi.test.ts`：ルールと保存・復元のテスト。
- `test/app.test.ts`：画面の操作ハンドラーを通した対局テスト。
- `test/navigation.test.ts`：タイトルの二分岐、新規・編集・対局、ファイルからの開始、メニュー中のAI停止のテスト。
- `test/human-ai.test.ts`：人対AIの自動応手、再読み込み、停止・再開、待った、200手を超える対局のテスト。
- `test/editor.test.ts`：盤面編集、可変サイズでの対局、初期配置の保存・復元のテスト。
- `test/setups.test.ts`、`test/setup-ui.test.ts`：配置のファイル出力・読み込み、ブラウザ内保存、上書き・複製・削除、保存失敗時のテスト。
- `test/ai.test.ts`：合法手、取り・詰みの選択、AI同士の対局とWorkerのテスト。

将棋の対局ロジックは以前の汎用ルールエンジンから独立しています。現在は盤面サイズと初期配置を編集でき、駒の動きや勝利条件の編集は今後の拡張対象です。
